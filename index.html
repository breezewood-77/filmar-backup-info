Filmar Backup Uploader

A private backup utility operated by Francis Brisebois. It uploads encrypted archives of the operator's local working files to a selected Google Drive backup folder and checks storage capacity. It is not offered as a public service.

Google access is limited to files created or selected for this app through the drive.file permission. The app does not request Gmail access or access to every file in the account.

The operator's separate, read-only verification process checks that backup archives can be recovered. Google Drive stores the encrypted archives; GitHub hosts the verification workflow.

Usage terms

This utility is intended only for the operator's private backup system. This website does not offer account registration, a paid service, or permission for others to connect accounts. Google account authorization remains controlled by the account owner.

Support is provided directly by the operator. The approved support email is displayed on Google's authorization screen.
