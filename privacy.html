Filmar Backup Uploader

Privacy policy

Prepared September 9, 2026. This notice describes the private backup utility operated by Francis Brisebois.

Data accessed and purpose

The utility uses the authorized Google account's email address to verify the intended account, storage-quota information to check capacity, and metadata for backup files and their selected destination folder. It creates encrypted backup archives containing the operator's chosen local working files. This data is used only to store, reconcile and verify the operator's backups.

Google permissions

The uploader requests Google's per-file drive.file permission. This permission can manage files created or selected for the app. The uploader's implementation creates and reads back backup archives; it does not use this permission to send email, change sharing, or delete unrelated Drive content.

Storage and verification

Archives are encrypted locally before upload to Google Drive. OAuth credentials are stored in a protected local backup directory. A separate read-only verifier runs on GitHub to download and recover backups. Its required credentials and recovery key are stored as encrypted GitHub secrets. Decrypted content is used for verification in temporary runner storage and is not included in published verification reports. Reports contain technical backup metadata and results.

Sharing and other uses

Google and GitHub provide the storage and verification services. Backup information is not sold, used for advertising, or used to train AI models by this utility. This informational website contains no analytics or tracking scripts.

Retention and control

The operator controls backup retention and removal. Revoking the app's access in Google Account settings stops future authorized API access; it does not itself remove archives already stored in Drive. The account owner can inspect or delete those archives in Drive. Removing access or recovery keys can prevent future backup or recovery operations.

Contact and changes

This is an operator-only application. Contact the operator directly using the support email shown on Google's authorization screen. This notice must be updated before the utility's data practices materially change.
